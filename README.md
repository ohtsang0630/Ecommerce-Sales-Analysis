# Ecommerce-Sales-Analysis
This is a SQL based analysis on an e-commerce sale data set.

# Overview
The dataset used for this project was provided by Kaggle. It contains a transnational data set of transactions between 01/12/2010 and 09/12/2011 for a UK based online retailer. The tools I used for this project were Excel, MySql, and Tableau. The objective of this project was to identify key drivers of revenue, high value customers, retention risks, and opportunities for business growth.
